# M7 — Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give `plat` a fully-configured, locally-validated release pipeline — goreleaser config (binaries, checksums, Homebrew tap), a build-time man page/shell-completion generator, a release GitHub Actions workflow, and a README with a ready-to-record demo — all verified via real dry-run tooling, with actual publishing left as a documented manual step.

**Architecture:** A new hidden `gendocs` cobra subcommand generates man pages and completion scripts from the live, already-built command tree (zero drift risk, since it's the exact tree `Execute()` runs). `.goreleaser.yaml` wires that subcommand into a `before.hooks` step, then cross-compiles, archives, checksums, and drafts a Homebrew formula — all runnable today via goreleaser's snapshot mode, which needs no git remote. A new `.github/workflows/release.yml` sits alongside the existing `ci.yml`, syntactically complete but dormant until a remote exists.

**Tech Stack:** `goreleaser` v2 (external tool, not a Go dependency — confirmed installed and working in this environment at `/Users/pat/go/bin/goreleaser`), `github.com/spf13/cobra/doc` (new Go dependency, man page generation), `vhs` (external tool, demo recording — confirmed installed and working at `/Users/pat/go/bin/vhs`, used here only for `.tape` syntax validation, not GIF rendering).

## Global Constraints

- **This milestone stays LOCAL-ONLY.** No task creates a GitHub repository, adds a git remote, pushes, or tags a real release. Every verification command in this plan is one that works with zero remote and zero GitHub token — confirmed empirically: `goreleaser build --snapshot --clean` and `goreleaser release --snapshot --clean` both succeed with no remote configured (they emit an informational "ignoring errors because this is a snapshot" line for the missing-remote check and proceed). Actually publishing (repo creation, push, tag, Homebrew tap setup) is documented as a manual runbook in this plan's Milestone Verification section, not executed.
- `goreleaser check` is NOT used as a verification command anywhere in this plan — confirmed it requires remote/SCM info to fully pass (it validates the `release:` stanza against a repository's remote) and will always report a remote-related error in this local-only repo. That's expected, not a defect. `goreleaser build --snapshot --clean` / `goreleaser release --snapshot --clean` are this plan's real, always-runnable local checks.
- `root.CompletionOptions.DisableDefaultCmd = true` is REMOVED entirely from `cmd/plat/main.go` (not flipped to an explicit `false` — the line is deleted, relying on cobra's zero-value default), making `plat completion bash|zsh|fish|powershell` a real, working, discoverable subcommand.
- `version`, `commit`, `date`, `builtBy` are four sibling `package main` string vars in `cmd/plat/main.go` (not a struct) — confirmed this exact shape works end-to-end with goreleaser's default-style ldflags (`-X main.version=... -X main.commit=... -X main.date=... -X main.builtBy=...`) because the Go linker resolves `-X main.xxx` by the **package name** `main`, not by import path, regardless of which directory that `package main` lives in.
- `cmd/plat/gendocs.go`'s `gendocs` subcommand is `Hidden: true` and never meant to be invoked by an end user — only by `.goreleaser.yaml`'s `before.hooks` and this plan's own tests. It operates on the literal, already-fully-built `root` command tree (passed to its constructor), not a hand-duplicated copy — this is what guarantees generated docs/completions can never drift from the real CLI surface.
- No `plat man` subcommand is added. Man pages are generated only as a build-time artifact (via `gendocs`), bundled into release archives.
- `.goreleaser.yaml` uses goreleaser v2's real, empirically-confirmed schema: `version: 2` at the top; `archives[].formats` is a **list** (`formats: [tar.gz]`), not a singular `format:` string; `checksum` (singular) has a `name_template` field; `brews:` is deprecated-but-functional (goreleaser's own runtime warning recommends `homebrew_casks` for GUI-app distribution, but `brews:` remains the correct mechanism for a traditional CLI Formula tap, which is what this milestone's spec asks for — used deliberately, with a comment documenting the tradeoff).
- Every task that modifies a pre-existing file must confirm that package's pre-existing tests still pass unmodified.

```go
package main

import (
	"fmt"
	"os"
	"path/filepath"

	"github.com/spf13/cobra"
	"github.com/spf13/cobra/doc"
)

// newGendocsCommand returns a hidden subcommand that generates man pages
// and shell completion scripts for root's full (non-hidden) command tree
// into <output-dir>/man and <output-dir>/completions. It is invoked by
// goreleaser's before.hooks at release build time (`go run ./cmd/plat
// gendocs <dir>`), never by an end user — operating on the SAME live
// root command that Execute() runs means generated docs can never drift
// from the real CLI surface, and cobra's man/completion generators
// already skip any command marked Hidden (the whois/merge debug
// subcommands never appear in generated output).
func newGendocsCommand(root *cobra.Command) *cobra.Command {
	return &cobra.Command{
		Use:    "gendocs <output-dir>",
		Short:  "Generate man pages and shell completions (internal, used by goreleaser)",
		Hidden: true,
		Args:   cobra.ExactArgs(1),
		RunE: func(cmd *cobra.Command, args []string) error {
			return genDocs(root, args[0])
		},
	}
}

func genDocs(root *cobra.Command, outputDir string) error {
	manDir := filepath.Join(outputDir, "man")
	compDir := filepath.Join(outputDir, "completions")
	if err := os.MkdirAll(manDir, 0o755); err != nil {
		return fmt.Errorf("gendocs: creating %s: %w", manDir, err)
	}
	if err := os.MkdirAll(compDir, 0o755); err != nil {
		return fmt.Errorf("gendocs: creating %s: %w", compDir, err)
	}

	if err := doc.GenManTree(root, &doc.GenManHeader{
		Title:   "PLAT",
		Section: "1",
		Source:  "plat " + version,
		Manual:  "plat Manual",
	}, manDir); err != nil {
		return fmt.Errorf("gendocs: generating man pages: %w", err)
	}

	completions := []struct {
		filename string
		gen      func(f *os.File) error
	}{
		{"plat.bash", func(f *os.File) error { return root.GenBashCompletionV2(f, true) }},
		{"plat.zsh", func(f *os.File) error { return root.GenZshCompletion(f) }},
		{"plat.fish", func(f *os.File) error { return root.GenFishCompletion(f, true) }},
		{"plat.ps1", func(f *os.File) error { return root.GenPowerShellCompletionWithDesc(f) }},
	}
	for _, c := range completions {
		f, err := os.Create(filepath.Join(compDir, c.filename))
		if err != nil {
			return fmt.Errorf("gendocs: creating %s: %w", c.filename, err)
		}
		genErr := c.gen(f)
		closeErr := f.Close()
		if genErr != nil {
			return fmt.Errorf("gendocs: generating %s: %w", c.filename, genErr)
		}
		if closeErr != nil {
			return fmt.Errorf("gendocs: closing %s: %w", c.filename, closeErr)
		}
	}
	return nil
}
```

## Install

# go install github.com/patramsey/plat/cmd/plat@latest

## Usage

```bash
# Basic lookup — auto-detects a styled human view on a terminal, plain
# text when piped
plat example.com

# Multiple domains in one invocation
plat example.com example.org

# Machine-readable output
plat example.com -o json | jq .expires
plat example.com example.org -o ndjson

# Include raw source payloads alongside the merged record
plat example.com -o json --raw

# Restrict which sources are queried
plat example.com --source rdap       # registry + registrar RDAP only
plat example.com --source whois      # registry + registrar WHOIS only
plat example.com --source registry   # registry RDAP + registry WHOIS only
plat example.com --source registrar  # registrar RDAP + registrar WHOIS only

# Skip the registrar RDAP related-link hop
plat example.com --no-follow

# Adjust the per-source timeout (default 5s)
plat example.com --timeout 10s

# Version and shell completions
plat version
plat completion bash > /etc/bash_completion.d/plat
plat completion zsh > "${fpath[1]}/_plat"
```

## Output & Provenance

Every field in `plat`'s output carries the list of sources that agreed on
its value. Where sources disagree, the conflict is recorded, not silently
dropped — visible in both the styled/plain human views and in `-o json`'s
`conflicts[]` array. GDPR-style redaction is modeled explicitly, not
mistaken for a literal contact name.

The `-o json`/`-o ndjson` wire format is a versioned, stable schema — see
[`docs/schema.md`](docs/schema.md) for the full field-by-field reference.

## Exit Codes

| Code | Meaning |
|---|---|
| `0` | At least one source returned usable data |
| `1` | Every attempted source agrees the domain doesn't exist |
| `2` | Usage error (bad flag, invalid domain input) |
| `3` | Total lookup failure (no source reachable, or ambiguous failure state) |

For multiple domains in one invocation, the overall exit code is the worst
of every individual domain's code.
